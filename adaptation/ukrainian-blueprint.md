# Ukrainian Adaptation Blueprint for ICNT

**Current structure (MOH)**: Internatura psychiatry ≈ 22 months (3432 hours: ~6 months educational / 936 h + 16 months practical).

## Enhancements within existing framework
- Educational block: +60–80 h Evidence-Based Practice & Meta-Analysis Literacy; +40 h Introduction to Syndrome Analysis (Luria qualitative method, free of ideological overreach).
- Practical block: Longitudinal outpatient caseload with ≥1 supervised long psychotherapy case (20–40 sessions, preferably recorded); optional concentrated Neuropsychology elective (200–300 clinical hours).
- Integration of war-related trauma modules and mhGAP for primary care interface.
- Dual-track option: Core psychiatry + extended neuropsychology or psychotherapy specialization via CPD / additional time.

Compatible with existing programs (Kharkiv NMU, NMU Bohomolets, Shupyk). Enhances rather than replaces statutory requirements.
