# Module: Clinical Neuropsychological Assessment, Syndrome Analysis & Rehabilitation

**Duration**: 200–300 clinical hours + 80–120 didactic (as core/elective in Ukrainian ординатура or dual track).

**Competencies**: Minnesota Functional (Assessment, Intervention) + Foundational (Neuroscience & Brain-Behavior, Science-Practice Integration).

## Learning Outcomes
- Conduct hypothesis-driven assessment using qualitative syndrome analysis (Luria: primary factor → secondary symptoms → preserved functions → functional system).
- Integrate with flexible standardized batteries.
- Formulate functional diagnosis and rehab plan.
- Critically appraise evidence for cognitive interventions.

## Content Outline
1. Brain-Behavior Foundations & Updated Luria Model
2. Qualitative Syndrome Analysis Protocol (observation → symptom → factor → syndrome → rehab hypothesis)
3. Standardized Assessment & Integration
4. Rehabilitation (Luria-Tsvetkova + evidence-based methods)

## Assessment
Portfolio of detailed reports with syndrome analysis, observed assessments, supervisor ratings.

**Ukrainian fit**: Concentrated rotation or elective within practice block; full depth via dual track or CPD.
