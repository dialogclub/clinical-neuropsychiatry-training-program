# clinical-neuropsychiatry-training-program

Integrative Clinical Neuropsychiatry Training (ICNT) system: synthesis of Houston/Minnesota Conference guidelines, ACGME psychiatry requirements, RCPsych, EuroPsy, NICE, WHO mhGAP, and Ukrainian standards.

Designed for Ukrainian/Eastern European context with global applicability. Combines clinical depth of observation and Luria syndrome analysis with rigorous evidence-based practice (meta-analyses, network MAs, guidelines).

## Structure
- `soviet-era/` — historical sources and critique
- `decision-trees/` — evidence-based pathways for major disorders
- `modules/` — detailed syllabi
- `adaptation/` — Ukrainian implementation blueprint

Living document — expand modules, add rubrics, digital tools as needed.
